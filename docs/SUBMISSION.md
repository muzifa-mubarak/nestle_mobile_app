# Assessment submission package

Section 21 of the PRD asks for a hosted API, a release APK, this source tree, and a short demo video. This file is the checklist for what is in the repository and what still has to be produced on a machine that can build Android and publish HTTPS.

## In this repository

- FastAPI app in `backend/`, with attendee routes, the Congress Assistant, and organizer routes under `/api/v1/admin`.
- Browser attendee preview at `/` and the admin portal at `/admin/`.
- Flutter app in `mobile_app/`.
- Schema migration `backend/alembic/versions/001_initial.py`. Local startup also creates tables.
- Seed: `cd backend && .venv/bin/python scripts/seed.py`
- Assistant checks: `cd backend && .venv/bin/python scripts/eval_ai.py`
- API schema: `docs/openapi.json` (regenerate with `cd backend && .venv/bin/python scripts/export_openapi.py`)
- Tests: `cd backend && .venv/bin/pytest`
- Environment template: `backend/.env.example`. Do not commit `backend/.env` or API keys.

## Still required outside this machine

1. **Public HTTPS API.** Deploy `backend/` and set `API_BASE_URL` in the app to that origin. The release build must not call localhost or cleartext HTTP.
2. **Release APK.** With Flutter installed, from `mobile_app/`:

   ```bash
   flutter build apk --release --dart-define=API_BASE_URL=https://YOUR_HOST/api/v1
   ```

   Copy the universal APK to `nmc-congress-v1.0.0.apk`. Minimum SDK is 26. The main manifest needs `INTERNET` and must not allow cleartext traffic.
3. **Demo video, 2–3 minutes**, recorded on a device: register, home, agenda, speakers, name tag, a vote seen on a second phone, a question, one factual assistant answer, and one unknown or off-topic question.

Flutter is not installed in this workspace, and there is no public host configured here, so those three artifacts are not generated by the local servers.
